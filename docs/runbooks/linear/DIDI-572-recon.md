# DIDI-572 recon (item 0) — paste as Linear comment

## (a) What the docs answer

| Question                                      | Answer (with links)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **OpenNext under `wrangler preview`?**        | Build with `opennextjs-cloudflare build`, then deploy the preview with **`npx wrangler preview`** (not `opennextjs-cloudflare preview`, which runs `wrangler dev`). [OpenNext Cloudflare README](https://github.com/opennextjs/opennextjs-cloudflare/blob/main/packages/cloudflare/README.md); [Workers Previews get started](https://developers.cloudflare.com/workers/previews/get-started/).                                                                                                     |
| **Preview bindings: `previews` vs inherited** | Previews **do not inherit** production `vars`, storage, queues, etc. Define non-prod bindings in `previews`. **`assets` / `ASSETS`** stay **top-level only**; `wrangler preview` uploads assets from the branch. [Configuration — What goes in the `previews` block](https://developers.cloudflare.com/workers/previews/configuration/).                                                                                                                                                            |
| **`ASSETS`, `IMAGES`, self-reference**        | **`ASSETS`:** top-level `assets` only (documented). **`IMAGES`:** add under `previews.images` if code reads `env.IMAGES` ([configuration table](https://developers.cloudflare.com/workers/previews/configuration/)). **`WORKER_SELF_REFERENCE`:** service bindings from a Preview call the bound Worker’s **production** deployment ([configuration](https://developers.cloudflare.com/workers/previews/configuration/), [Previews overview](https://developers.cloudflare.com/workers/previews/)). |
| **Preview secrets**                           | Shared secrets: `wrangler preview base-config secret put NAME`. Per-preview override: `wrangler preview secret put NAME --name <preview>`. [Configuration — Secrets](https://developers.cloudflare.com/workers/previews/configuration/).                                                                                                                                                                                                                                                            |
| **D1 `migrations apply` and `previews`**      | Migrations target a **database name/ID** in config; remote apply uses top-level `d1_databases`, not the `previews` block. Use a minimal generated config or explicit non-prod DB ([configuration — D1 migrations](https://developers.cloudflare.com/workers/previews/configuration/)); repo fix: `scripts/prepare-wrangler-config.mjs --target d1-migrate-nonprod` ([0020](../decisions/0020-d1-database-id-injection.md)).                                                                         |
| **Preview URL format**                        | `<preview-name>-<worker-name>.<subdomain>.workers.dev` (e.g. `pr-42-we-met.<account>.workers.dev`). Returned in `wrangler preview --json` as `.preview.urls[0]`. [environments.md](../architecture/environments.md); [Examples](https://developers.cloudflare.com/workers/previews/examples/).                                                                                                                                                                                                      |
| **Delete preview**                            | `npx wrangler preview delete --name <name> --skip-confirmation`. PR cleanup pattern in [Examples — Delete closed pull request Previews](https://developers.cloudflare.com/workers/previews/examples/).                                                                                                                                                                                                                                                                                              |

**Preview trigger decision:** GitHub Action running `wrangler preview` ([0019](../decisions/0019-pr-preview-github-action.md)), not Cloudflare Git integration.
