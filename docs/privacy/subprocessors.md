# Subprocessors (We Met)

Human-readable list aligned with the public privacy page (`src/components/landing/PrivacyPolicyContent.tsx`) and [`data-map.yml`](./data-map.yml). Outbound mail uses **one** of the two email subprocessors below at a time (`app_settings.email_provider`); both are implemented in the product.

| Subprocessor                 | Role                                                                                                            | Personal data they receive (when applicable)                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Cloudflare**               | Hosts the app and consumer Workers; D1, R2, Queues, Turnstile, rate limiting, Workers Observability logs/traces | Data described under `processors: [Cloudflare]` in `data-map.yml` (account and card data in D1/R2, queue payloads with visitor leads, technical data such as IP for abuse protection, etc.)                                                                                                                                                                                                                                                                                                               |
| **Cloudflare Email Service** | Sends contact-exchange and related mail when `email_provider` is `cloudflare`                                   | For each outbound message: recipient address, sender address and display name, optional reply-to, subject, plain-text and HTML bodies, and attachments (including visitor contact cards). Same message types as the Gmail path: owner lead notifications (visitor name, email, phone; append with job title, company, note) and visitor follow-up (card owner names, role, photo URL in body, vCard with owner email and name). Source: `src/email/cloudflare-sender.ts`, `src/followup-email-consumer/`. |
| **Google**                   | Google sign-in (OAuth ID token)                                                                                 | Google account subject, email, name, and email-verified flag during sign-in; we persist sub, email, and name only. Source: `src/app-auth/google-oauth.ts`.                                                                                                                                                                                                                                                                                                                                                |
| **Google (Gmail API)**       | Sends contact-exchange and related mail when `email_provider` is Gmail or unset                                 | Same per-message content as Cloudflare Email Service above, submitted via Gmail API from a delegated mailbox. Messages are stored in that mailbox per Google mailbox policy. Source: `src/email/gmail-sender.ts`, `src/followup-email-consumer/`.                                                                                                                                                                                                                                                         |

Cloudflare Email Service retention and logging after handoff are **not** documented in this repository (`verified: false` in the map until confirmed with vendor docs or maintainer).
